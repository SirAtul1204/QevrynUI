# Changelog

## 0.1.0 — 2026-11-12

- Initial Prism Satin component library with dark, light, and system themes.
- Buttons, links, form controls, selections, chips, cards, and accordions.
- Mobile-first layout primitives, alerts, and queued toast notifications.
- Dialogs, four-edge drawers, and tooltips with accessible keyboard behavior.
- Compiled styles, ES modules, CommonJS, TypeScript declarations, and MIT license.
